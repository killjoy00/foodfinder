# Repository agent instructions

## Portfolio mobile releases

Use the [mobilereleases registry and dashboard](https://github.com/killjoy00/mobilereleases) and [release request instructions](https://github.com/killjoy00/mobilereleases/blob/main/mobile-releases/RELEASE_REQUESTS.md) for mobile release work. The mobile source is registered for future release management. No verified signed publishing route is established. Review the current mobile documentation and build/store identity before configuring release delivery. Keep existing app-specific requirements and require explicit owner approval for production publishing. Never expose credentials or private account information.
